# Nathan Rullier — Portfolio

Personal portfolio site for **Nathan Rullier**, Creative Technologist — Montréal, QC.

Built with vanilla HTML / CSS / JS (no build step). Hosted on GitHub Pages.

## Live site

→ [nathanrullier.github.io](https://nathanrullier.github.io)

## Structure

```
index.html   — single-page portfolio
style.css    — all styles (custom properties, responsive grid)
script.js    — particle canvas, scroll reveal, pipeline animation
assets/      — images (add project screenshots here)
```

## Deploy

Push to the `main` branch of `NathanRullier/NathanRullier.github.io`. GitHub Pages serves it automatically.

```bash
git add .
git commit -m "update portfolio"
git push origin main
```
